## 二、合并方法

> 分卷是**纯字节切分**（`split`），不是压缩包，合并即可用，无需解压软件。

### Windows · PowerShell

```powershell
# 安装版
Get-Content .\混在日本-4.0.0-x64.part* -Encoding Byte -ReadCount 0 |
    Set-Content .\混在日本-4.0.0-x64.exe -Encoding Byte

# 便携版
Get-Content .\混在日本-便携版-4.0.0.part* -Encoding Byte -ReadCount 0 |
    Set-Content .\混在日本-便携版-4.0.0.exe -Encoding Byte
```

### Windows · 命令提示符 CMD

```cmd
copy /b 混在日本-4.0.0-x64.part00+混在日本-4.0.0-x64.part01+混在日本-4.0.0-x64.part02+混在日本-4.0.0-x64.part03+混在日本-4.0.0-x64.part04 混在日本-4.0.0-x64.exe
```

### Linux / macOS

```bash
cat 混在日本-4.0.0-x64.part*      > 混在日本-4.0.0-x64.exe
cat 混在日本-便携版-4.0.0.part*    > 混在日本-便携版-4.0.0.exe
```

### 7-Zip（图形界面）

选中 `*.part00` 右键 → **7-Zip → 提取到当前位置**，会自动串接全部同名分卷。

## 四、两个版本的区别

| | 安装版 | 便携版 |
|---|---|---|
| 安装 | 双击安装，可选安装目录 | 免安装 |
| 快捷方式 | 自动创建桌面 + 开始菜单 | 无 |
| 卸载 | 控制面板 / 卸载程序 | 直接删文件 |
| 存档位置 | `%APPDATA%\混在日本\saves\` | 同左 |

**推荐安装版**，除非需要放在 U 盘随身携带。

## 五、运行环境

- Windows 10 / 11，64 位
- **完全离线**，无需联网
- 无需安装 .NET / VC++ 等运行库
- 首次启动约 3–5 秒（初始化资源）

## 六、操作方式

- **鼠标左键点击** —— 全部交互（菜单、对话、选项、确认）
- 窗口为 9:16 竖屏，按屏幕高度自动缩放
- `F11` 切换全屏，`Alt+F4` 退出
