# 《混在日本》PC 单机版移植工程

> **项目代号**：Hun-JP-Offline (HJO)
> **目标**：将《混在日本》日本版（仅主游戏）移植为 PC 端离线单机游戏
> **状态**：第一阶段（可行性研讨与方案制定）已完成
> **日期**：2026-09-19

---

## 项目目标

| 目标 | 说明 |
|---|---|
| **平台** | PC（Windows 优先，可扩展 macOS/Linux） |
| **联网** | **完全离线**（仅内购保留自有渠道） |
| **范围** | **仅日本版主游戏** — 不含混一 / 美国版 / 热血高校 / 游戏厅（FC 模拟器） |
| **保真度** | 玩法 100% 保留，外观 1:1 还原 |
| **商业化** | 内购系统连接自有渠道，不影响商用 |

---

## 核心结论

> **✅ 项目可行，难度低于预期。**

游戏采用 **"纯客户端逻辑 + 服务端仅存档"** 架构：

- **全部玩法逻辑在客户端** —— `hun_min.js`（2.04 MB，6241 个函数），服务端**无任何玩法计算接口**
- **全部规则数据可获取** —— `gamedata.json`（424 KB）含 9 城 / 66 车 / 110 人 / 75 物品 / 33 兵种 / 24 货物
- **全部资源可获取** —— 实测 **60/60 主资源 + 40/40 音效抽样** 全部成功
- **只需适配 17 个接口** —— 全部为存档/排行/社团/支付类

**离线化 = 把 17 个 `$.ajax` 替换为本地实现。核心 2 MB 游戏逻辑一行不改。**

## 技术栈

| 层 | 选型 | 理由 |
|---|---|---|
| 运行时 | **Electron 28+** | Chromium 兼容性最佳；Node 环境可直接调支付 SDK；跨平台 |
| 打包 | electron-builder | 生成 NSIS / dmg / AppImage |
| 本地服务 | Node http / Express | 提供 `http://127.0.0.1`，规避 `file://` 的 CORS 限制 |
| 存档 | localStorage + 文件备份 | 沿用游戏原机制 + 防篡改加固 |
| 内购 | 自有渠道 SDK | 唯一联网点 |
