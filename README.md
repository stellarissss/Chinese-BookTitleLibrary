### 可行性结论

> **可行，且已完成。** 全部游戏资产可从 CDN 完整获取，玩法逻辑 100% 位于客户端 JS，
> 服务端接口仅 17 个且全部为存档 / 排行 / 帮会 / 支付类。

### 关键技术判断

- **资源**：美术资产以 **4 张精灵图集**（car / person / goods / building，200px 网格）打包，非数千散图；
  PC 端 `hasImgHD()` 恒为 `true`，**自动加载 HD 图集**。
- **数据**：`gamedata.json`（424KB）为**完整游戏规则库**，data-driven 设计，是离线化的关键抓手。
- **改造手法**：**不修改 `hun_min.js`**（字节级不变），改为运行时猴补丁
  `jQuery.ajax` + 路由表拦截 + 本地存档引擎；模块裁剪全部以开关驱动，可随时恢复。

### 技术栈

| 层 | 选型 |
|---|---|
| 运行时 | Electron 33.4.11（Chromium 130） |
| 打包 | electron-builder 24.x → NSIS 安装包 + 便携版 |
| 平台 | 仅 Windows x64 |
| 离线 | AJAX / XHR / fetch / WebSocket 全局拦截；外网请求归零 |
| 存档 | Windows 原生 KV + localStorage 双写 |
